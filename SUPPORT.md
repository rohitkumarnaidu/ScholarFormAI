# ScholarForm AI Support

Thank you for using ScholarForm AI! We offer both free community support and formal enterprise SLAs.

---

## 1. Community Support (Free)

| Channel | Purpose | Response Time |
| :--- | :--- | :--- |
| [GitHub Issues](https://github.com/rohitkumarnaidu/ScholarFormAI/issues) | Bug reports, feature requests, RFCs | 24-72 hours |
| [GitHub Discussions](https://github.com/rohitkumarnaidu/ScholarFormAI/discussions) | Q&A, ideas, community help | 24-72 hours |
| [Discord](https://discord.gg/scholarform) *(Community)* | Real-time chat, contributor coordination | Best-effort |

---

## 2. Weekly Office Hours

The core maintainers hold weekly virtual office hours for community members:

| Day | Time (UTC) | Focus Area |
| :--- | :--- | :--- |
| **Monday** | 15:00–16:00 | General Q&A, installation, and onboarding help |
| **Wednesday** | 15:00–16:00 | Technical deep-dives, pipeline architecture, and template design |
| **Friday** | 15:00–16:00 | Contributor office hours (PR reviews, mentoring, roadmap) |

Office hours are hosted in the project's Discord voice channels. Announcements and notes are posted in GitHub Discussions.

---

## 3. Professional & Enterprise Support

For institutions and research organizations requiring guaranteed SLAs, custom CSL/DOCX templates, or on-premises deployments:

| Tier | Response SLA | Scope | Contact |
| :--- | :--- | :--- | :--- |
| **Community** | 24-72 hours | Public GitHub issues and discussions | GitHub |
| **Standard** | 8 business hours | Private email support, priority bug fixes | <enterprise@scholarform.ai> |
| **Premium** | 2 business hours | Priority processing queue, bespoke journal templates, deployment assistance | <enterprise@scholarform.ai> |
| **Enterprise** | 1 hour | 24/7 support, custom pipeline development, SLA guarantees, self-hosted deployment | <enterprise@scholarform.ai> |

## 4. Before Opening an Issue

1. Check the [FAQ](docs/reference/FAQ.md) and [Troubleshooting Guide](docs/troubleshooting/troubleshooting.md).
2. Search existing [GitHub Issues](https://github.com/rohitkumarnaidu/ScholarFormAI/issues) and [Discussions](https://github.com/rohitkumarnaidu/ScholarFormAI/discussions).
3. Review the [User Guide](docs/guides/USER_GUIDE.md) and [API Reference](docs/reference/API_REFERENCE.md).

---

## 5. Security Vulnerabilities

**Do not open public issues for security vulnerabilities.** Report security issues confidentially following the instructions in [SECURITY.md](SECURITY.md) or by emailing <security@scholarform.ai>.
