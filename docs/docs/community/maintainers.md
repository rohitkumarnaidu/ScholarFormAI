## Roles & Responsibilities

### Core Team Member
- Full write access to repository.
- Responsible for reviewing and merging Pull Requests.
- Oversees release tagging, PyPI package publishing, and Docker Hub image deploys.
- Responds to security advisories within SLA windows.

### Module Maintainer
- Designated lead for specific submodules (e.g. `backend/app/pipeline/`, `frontend/`, `cli/`).
- Conducts technical triage for domain-specific issues.

---

## Issue Triage Policy

1. **New Issues**: Acknowledged within 48 hours.
2. **Bug Reports**: Assigned severity tag (`bug:critical`, `bug:high`, `bug:medium`, `bug:low`).
3. **Pull Requests**: Reviewed within 2 business days.

---

## Becoming a Maintainer

Contributors who demonstrate sustained, high-quality contributions, constructive code reviews, and community engagement may be nominated for maintainer status by an existing Core Team member. Nominations require a ⅔ majority vote of the Core Team.
