# Accessibility

## Commitment

AMF is committed to making academic formatting accessible to all users, regardless of ability.

## Current Status

### Web UI

- Semantic HTML structure
- Keyboard navigable interface
- ARIA labels on interactive elements
- Sufficient color contrast ratios
- Screen reader compatible

### CLI

- Terminal-based interface accessible via screen readers
- Clear, structured output
- Configurable output verbosity

### Documentation

- Written in plain, clear language
- Structured with proper heading hierarchy
- Alt text on images (where applicable)

## Compliance

We aim to meet WCAG 2.1 Level AA standards for the web interface.

## Known Gaps

- [ ] Focus indicators need improvement
- [ ] Skip navigation link needed
- [ ] Color-blind friendly palette verification needed
- [ ] Complete keyboard navigation testing

## How to Report Issues

If you encounter accessibility barriers, please:

1. Open a GitHub issue with label `accessibility`
2. Describe the barrier and your assistive technology
3. Suggest how we can improve
