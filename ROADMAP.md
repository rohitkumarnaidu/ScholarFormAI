# Roadmap

## Current Release (v1.0.0) ✅

- Core formatting engine with 9 citation styles
- RESTful API with FastAPI
- Web UI with Next.js
- CLI tool for terminal-based formatting
- Python SDK
- Docker deployment

## Short-term (v1.1 - v1.3)

### Formatting & Output
- [ ] PDF output support (via WeasyPrint or similar)
- [ ] Custom style creator UI
- [ ] User-defined style templates
- [ ] Table and figure formatting
- [ ] Equation support (LaTeX rendering in DOCX)

### Integration
- [ ] Overleaf/LaTeX project import
- [ ] Zotero/Mendeley reference import
- [ ] Google Docs integration
- [ ] GitHub Actions native action

### Platform
- [ ] Batch processing mode
- [ ] Webhook support for CI/CD pipelines
- [ ] API rate limiting dashboard

## Medium-term (v2.0)

### AI & Intelligence
- [ ] AI-powered citation fixing and suggestion
- [ ] Intelligent section structure recommendations
- [ ] Abstract summarization and keyword extraction
- [ ] Plagiarism detection integration
- [ ] Language enhancement suggestions
- [ ] Automated figure/table captioning

### Platform
- [ ] User accounts and project management
- [ ] Team collaboration features
- [ ] Version history and diffing
- [ ] Plugin marketplace
- [ ] Custom template gallery
- [ ] Advanced analytics dashboard

### Enterprise
- [ ] SSO/SAML authentication
- [ ] Audit logging
- [ ] Role-based access control
- [ ] On-premise deployment option
- [ ] High availability configuration
- [ ] Managed cloud service

## Long-term (v3.0+)

- Real-time collaborative editing
- Desktop applications (Electron/Tauri)
- VS Code extension
- CI/CD native integrations (GitLab, Jenkins)
- Marketplace for community styles and templates
- Multi-language manuscript support
- Accessibility compliance tools
- Integration with journal submission systems
