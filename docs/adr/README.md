# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the ScholarForm AI project.

An ADR documents a significant architectural decision, including the context, the decision itself, and the consequences. For new decisions, copy `TEMPLATE.md` and follow the established format.
