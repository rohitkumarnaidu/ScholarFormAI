# ScholarFormAI Best Practices

This directory contains comprehensive guides on how to use ScholarFormAI securely, efficiently, and effectively in a production environment.

## Guides

1. **Security & Data Privacy**
   - Managing API keys securely in CI/CD.
   - PII detection and redaction before sending documents to the API.

2. **Performance Optimization**
   - When to use Synchronous vs. Asynchronous API endpoints.
   - Batch processing massive document archives.
   - Managing Websocket connection lifecycles for real-time editors.

3. **Template Design**
   - Designing custom templates for proprietary institutional formats.
   - CSL (Citation Style Language) best practices for custom reference rendering.

4. **Error Handling**
   - Implementing exponential backoff.
   - Graceful degradation on LLM API timeouts.
