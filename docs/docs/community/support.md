# Support

## Getting Help

| Channel | Purpose | Response Time |
|---------|---------|---------------|
| [GitHub Issues](https://github.com/amf/automated-manuscript-formatter/issues) | Bug reports, feature requests | < 72 hours |
| [GitHub Discussions](https://github.com/amf/automated-manuscript-formatter/discussions) | Q&A, ideas, show-and-tell | < 1 week |
| [Documentation](https://amf.dev/docs) | Self-service guides | Always available |
| [Stack Overflow](https://stackoverflow.com/questions/tagged/amf) | Community Q&A | Community-driven |

## Enterprise Support

For SLAs, consulting, and enterprise contracts:
- **Email**: enterprise@amf.dev
- **Response**: < 4 hours for critical issues

## Filing Issues

Before filing, please:
1. Search existing issues
2. Check the troubleshooting guide
3. Use the appropriate template (bug report / feature request)

## Security Issues

Report security vulnerabilities to **security@amf.dev**. Do not file public issues for security bugs.
