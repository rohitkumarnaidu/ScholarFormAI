# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, inclusive, and harassment-free experience for everyone in our community.

## Standards

**Positive behavior:**

- Demonstrating empathy and kindness
- Respecting differing viewpoints
- Giving and accepting feedback gracefully
- Focusing on what's best for the community

**Unacceptable behavior:**

- Harassment, trolling, or insults
- Discriminatory language or imagery
- Publishing others' private information
- Any conduct inappropriate in a professional setting

## Enforcement

Violations can be reported to <conduct@amf.dev>. All reports will be reviewed and investigated promptly.

Project maintainers are responsible for enforcing these standards and may take corrective action including warnings, temporary bans, or permanent bans.

## Scope

This Code of Conduct applies to all community spaces — GitHub issues, discussions, pull requests, and any other project-related communication channels.
