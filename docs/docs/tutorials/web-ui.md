# Web UI Walkthrough

## Step 1: Start the Services

```bash
docker compose up -d
```

Open [http://localhost:3000](http://localhost:3000).

## Step 2: Enter Manuscript

1. Click **Format** in the navigation
2. Paste your manuscript text into the editor
3. Or upload a `.md`, `.tex`, or `.txt` file

## Step 3: Select Style

Choose a citation style from the dropdown:
- **APA 7th** — Social sciences, psychology, education
- **MLA 9th** — Humanities, literature, arts
- **Chicago 17th** — History, arts, humanities
- **IEEE** — Engineering, computer science
- **Harvard** — Multi-discipline (UK/AU)
- **Vancouver** — Biomedical sciences
- **Turabian** — Student papers, theses
- **ACS** — Chemistry
- **AMA 11th** — Medical research

## Step 4: Configure Options

Adjust formatting:
- Page size (A4, Letter, Legal)
- Font (Times New Roman, Arial, Calibri, etc.)
- Font size (10-14pt)
- Line spacing (1.0-2.5)
- Margins (0.5-2.0 inches)

## Step 5: Preview and Download

1. Click **Preview** to see the formatted output
2. Review the HTML preview
3. Click **Download DOCX** to save
