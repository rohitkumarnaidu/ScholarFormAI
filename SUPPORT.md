# Support

Welcome to the ScholarForm AI support page! We offer several ways for you to get help, depending on your needs.

## Community Support

For general questions, discussions, and community support, please use:

- **[GitHub Discussions](https://github.com/rohitkumarnaidu/ScholarFormAI/discussions)**: The best place for Q&A, sharing ideas, and connecting with other users.
- **[Discord / Slack]**: Join our community chat (link coming soon).

## Bug Reports and Feature Requests

If you have found a bug or have a feature request:

- **[GitHub Issues](https://github.com/rohitkumarnaidu/ScholarFormAI/issues)**: Check if the issue has already been reported. If not, open a new issue using the appropriate template.

## Documentation

Our documentation is the best place to start if you are looking for guides, API references, or tutorials:

- **[Documentation Index](docs/README.md)**: Comprehensive documentation covering setup, architecture, and usage.
- **[FAQ](FAQ.md)**: Frequently Asked Questions.

## Security Vulnerabilities

If you discover a security vulnerability, please do **NOT** open a public issue. 
Refer to our [Security Policy](SECURITY.md) for detailed instructions on how to securely report vulnerabilities.

## Enterprise Support

For enterprise deployments or priority support, please contact our team at support@scholarform.ai.
